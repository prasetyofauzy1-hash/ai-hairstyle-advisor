# FaceBench FFHQ: Phase 3 external evaluation

Generated by `python -m ml.evaluation.facebench`. See [reproduction and protocol](../../../../docs/datasets.md#follow-up-public-pre-labeled-evaluation-data-2026-11-26).

Of 81 FaceBench FFHQ photos, 61 passed quality checks. Of those, 0 lacked an identity embedding and 50 were flagged as possible matches at SFace cosine ≥ 0.363. The [identity audit](identity_review.csv) confirmed 2 of those flags. Only the 2 confirmed matches across 58 reviewed photos were excluded for identity. **59 photos were scored.**

The pools conservatively include all niten19 archive photos and the full FFHQ train split, not just the rows used to fit the artifacts. Unconfirmed is not proof of different identities. No photos, embeddings, names or per-photo predictions are published.

Macro-F1 equally weights the shapes with retained ground-truth examples (diamond, heart, oblong, oval, round, square); predicting an unsupported shape still counts as an error. The [Uzy benchmark](../kaggle_plus_ffhq_ai/README.md) weights its own labeled classes, so the scores are not directly comparable. The small retained set cannot establish a model ranking or performance on unsupported classes.
