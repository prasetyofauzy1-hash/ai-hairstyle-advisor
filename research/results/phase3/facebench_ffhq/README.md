# FaceBench FFHQ: Phase 3 external evaluation

Generated by `python -m ml.evaluation.facebench`. See [reproduction and protocol](../../../../docs/datasets.md#follow-up-public-pre-labeled-evaluation-data-2026-11-26).

Of 81 FaceBench FFHQ photos, 61 passed quality checks. Of those, 0 lacked an identity embedding and 50 were flagged as possible matches to at least one reference photo at SFace cosine ≥ 0.363. **11 photos were scored.**

Macro-F1 equally weights the shapes with retained ground-truth examples (heart, oval, round, square); predicting an unsupported shape still counts as an error. The [Uzy benchmark](../kaggle_plus_ffhq_ai/README.md) weights its own labeled classes, so the scores are not directly comparable. The small retained set cannot establish a model ranking or performance on unsupported classes.
